# Fiche Chrome Web Store — brouillon

## Nom

WikiMasters Tools

## Résumé

Prix moyens, collection, échanges et paquets pour WikiMasters. Extension non officielle.

## Description

WikiMasters Tools ajoute des prix moyens par rareté aux cartes de la collection
et du marché. Son panneau permet de charger la collection, classer les cartes
par prix estimé, examiner un échange et préparer une mise en vente confirmée.
Sur la page des paquets, il peut ouvrir une quantité choisie et afficher un
récapitulatif trié par prix. Il s'arrête si le jeu demande une vérification ou
impose une limite.

Les réglages et le cache des prix restent dans le profil du navigateur. Aucun
serveur propre ni collecte de données. Pour utiliser plusieurs comptes, un
profil Chrome ou Dia distinct est nécessaire pour chaque compte.

Projet non officiel, 100 % vibecodé. Les règles de WikiMasters interdisent
l'automatisation et les multi-comptes ; l'utilisateur assume le risque de
sanction. Lire la politique de confidentialité du projet avant installation.

## Justification des permissions

- `storage` : conserver les réglages et les prix publics mis en cache.
- `https://www.wiki-masters.com/*` : afficher les commandes à côté du jeu et
  appeler ses API avec la connexion déjà présente dans le navigateur.
